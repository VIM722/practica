Tu cotización, paso a paso.

Solo necesitas unos datos para conocer el importe de tu servicio.

  1. Identifica al cliente

    Escribe un nombre o razón social de hasta 100 caracteres. Selecciona Nuevo, Frecuente o Institucional para aplicar el descuento correspondiente.

  2. Selecciona un servicio

    Elige diagnóstico de computadora, mantenimiento preventivo o instalación de software. Cada cotización corresponde a un servicio del catálogo.

  3. Indica la cantidad

    Ingresa un número entero entre 1 y 5. Puedes usar los botones de cantidad o escribir el número directamente.

  4. Genera y conserva tu resumen

    Pulsa Generar cotización. Verás el subtotal, el porcentaje de descuento, el ahorro y el total. Desde el resumen puedes imprimir o guardar un PDF con la función de tu navegador.

Antes de empezar

¿Cómo se calcula el importe?

El precio unitario se multiplica por la cantidad. Al subtotal se le resta el descuento: 0% para clientes nuevos, 10% para frecuentes y 15% para institucionales.

¿Se guardan mis datos?

La aplicación usa los datos únicamente para generar el resumen actual. No cuenta con un historial de clientes ni almacena cotizaciones. Imprime o guarda el resumen antes de cerrar la página.

¿El total incluye cargos adicionales?

No se agregan cargos al catálogo de esta práctica. Los importes están expresados en soles peruanos.
